# andrewvalentini.github.io

Source for my personal academic website: **https://andrewvalentini.github.io**

I'm a Physics PhD student at the University of Florida working on generative models for materials discovery.

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open http://localhost:4000. Alternatively, run `docker compose up`.
